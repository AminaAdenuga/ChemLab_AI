ChemLab AI
Project Overview
ChemLab AI is an educational machine-learning application designed to classify chemical reactions based on their reactants and molecular features.

Problem Statement
Identifying and classifying chemical reactions requires an understanding of reactants, molecular structures and reaction patterns. ChemLab AI explores how machine learning can support chemistry education by helping students recognise different reaction categories.

Project Objectives
Develop a machine-learning model for classifying supported chemical reactions.
Use RDKit to extract molecular features from chemical structures.
Train and evaluate classification models.
Develop a simple web application for users to interact with the model.
Provide educational explanations for supported reaction categories.
Target Users
Chemistry students, educators and learners interested in chemical reactions and artificial intelligence.

Project Status
Currently in the engineering environment setup stage.

Limitations
This is an educational prototype. Its predictions will be limited to the reaction classes and chemical patterns represented in its validated dataset. It is not intended to predict arbitrary chemical reactions.
